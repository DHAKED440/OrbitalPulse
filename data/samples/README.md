# OrbitalPulse demo samples

Every image in these scenario folders is deterministically generated by `scripts/generate_demo_samples.py`. They are synthetic visual fixtures, not satellite/aerial observations and not geospatial evidence.

Each folder contains matching `before.png` and `after.png` files plus `scenario.json` metadata. To regenerate all pairs, run `python scripts/generate_demo_samples.py` from the repository root. The backend discovers complete pairs and the frontend loads each pair into the ordinary analysis workflow.
